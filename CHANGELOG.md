# Changelog

All notable changes to Saber are recorded here. Versions follow
[Semantic Versioning](https://semver.org/).

## 0.2.0

### Breaking changes

- Model artifacts store their training provenance in `training_provenance.json` (was `provenance.json`). The `.provenance.json` suffix and the bare `provenance.json` name are reserved for the run-level provenance sidecar shared by the sibling CLIs. Artifacts saved by earlier versions still load and verify, because the loader reads file names from `manifest.json`.

## 0.1.0

First public release, published on PyPI as `saberlib`.

- Classical supervised classification and regression with a static algorithm catalog (`saber.ALGORITHMS`).
- `train`, `validate`, `tune`, `benchmark`, `predict` and `evaluate` as plain functions, with leakage-safe preprocessing fitted inside each training fold.
- Partitions come from an explicit `PartitionPlan` or are generated by BioSieve through `BioSievePartitionConfig` (optional extra `saberlib[biosieve]`).
- Grid, random, successive-halving and Optuna optimization, evaluated on a protected final test.
- Multi-representation benchmarking with seeds, tuned and untuned modes and dummy baselines.
- Model and benchmark artifacts (`save_model`, `load_model`, `save_benchmark`, `load_benchmark`) with checksums, dataset and partition fingerprints and environment metadata.
- The `saber` CLI: `saber run CONFIG` runs a YAML config, plus `saber models` and `saber artifact`.
